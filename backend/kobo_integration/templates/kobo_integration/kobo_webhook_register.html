How it works
  1. Enter your Kobo API token and click Register Webhook.
  2. This app calls the KoboToolbox API to register {{ webhook_url }} as a REST Service on your project.
  3. KoboToolbox will automatically send every new submission to this app in real time.
  4. Your KOBO_WEBHOOK_TOKEN is pre-set as a custom header so submissions are authenticated.
